# Code leren

Code leren turns what the agent just built into a short exercise. After a turn that changed code, a
box appears over the composer with a piece of that code: the lines above and below stay visible, one
part is left out, and you type it back. The box names the file and says what was built and what the
missing part must do.

**Nakijken** sends your attempt to the text generation model from Settings, not to the
thread's agent, so practising does not add to the thread's context. The review says whether your code
is right, almost right or not yet, and why. Change your answer and check it again, or ask for a hint,
the answer, or a new exercise.

Open **Code leren** from the right panel's menu, or with the panel button in the box. The panel
chooses how much you write yourself: **Invullen** (part of a line), **Een regel** or **Een blok** of
lines. It also turns the exercise after each turn on or off, and lists earlier exercises of the
thread. A turn that changed no code gets no exercise; **Nieuwe oefening** then picks code from
earlier in the thread.

Exercises are kept in this browser or app window's storage, per thread. Making one costs a small
generation on the text generation model each turn while the setting is on.
